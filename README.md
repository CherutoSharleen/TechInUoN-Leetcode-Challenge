# TechInUoN-Leetcode-Challenge
Daily Leetcode challenges for the TechInUoN club. The challenges are for DSA Practice and are implemented in Python

## Educational mini-project in this repository

- **Path:** `search_structures/trie_demo`
- **Focus:** trie insert/search/delete/prefix operations with helper utilities.
- **Run:** `cd search_structures/trie_demo && python cli.py`
- **Test:** `cd search_structures/trie_demo && python -m unittest discover -s tests -p "test_*.py"`
